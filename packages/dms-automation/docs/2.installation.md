# Installation

::steps
### Add the module

```bash [Terminal]
ajs project modules add @antelopejs/dms-automation
```

The command adds a `dms-automation` entry to `antelope.config.ts` and installs the package. The module implements `@antelopejs/interface-dms-automation`, so modules that declare nodes find it automatically.

### Configure it (optional)

```ts [antelope.config.ts]
"dms-automation": {
  source: { type: "package", package: "@antelopejs/dms-automation", version: ">=0.4.0 <1.0.0" },
  config: {
    runs: { retentionDays: 30 },
    httpRequest: { blockPrivateNetwork: true },
  },
},
```

[Configuration](/docs/modules/automation/configuration) lists every option.

### Restart the backend, then the frontend

The module registers its Vue frontend module (`DmsAutomation` component prefix) when the backend starts. Restart `ajs dms dev`, or rebuild with `ajs dms build`, afterwards.

### Create a procedure

Open **Modules → Automation**. The Overview offers three recipes to start from: **Forward a webhook**, **Send a scheduled digest** and **Run it on demand**.
::

::note
Upgrading from the CMS-era package? Version 0.0.1 renamed everything (`cms-automation` database, `cmsAutomation` config key, i18n namespace) with no migration path: recreate the deployment.
::
